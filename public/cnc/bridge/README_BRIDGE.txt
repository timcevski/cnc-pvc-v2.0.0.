=============================================================================
  CNC Dispenser V2.0 — Mach3 Bridge (32-bit C++ Win32 без .NET)
=============================================================================

Овој пакет ги содржи изворните датотеки за локалниот комуникациски мост
помеѓу CNC Dispenser V2.0 (во прелистувачот) и Mach3 контролерот.

Што има во папката bridge\:
  1. Mach3Bridge.cpp       — 100% нативен C++ Win32 код (Winsock2 + Mach3 COM)
                             без .NET, без Python, без Node.js и без DLL-а.
  2. Build_Mach3Bridge.bat — 1-клик скрипта за правење на Mach3Bridge.exe
                             (во главната папка, веднаш до index.html).

Како да го направите Mach3Bridge.exe (само еднаш):
  1. На Windows XP / Windows 7 / Windows 10/11 треба да имате 32-bit C++
     компајлер (TDM-GCC 32-bit / MinGW-w64 i686 или Visual Studio x86 Tools).
     ВАЖНО: Користете 32-bit (x86) компајлер затоа што Mach3 е 32-bit!
  2. Двоен клик на Build_Mach3Bridge.bat.
  3. Ќе се креира Mach3Bridge.exe во главната папка до index.html.

Како се користи при работа на машина:
  1. Прво стартувајте го Mach3 и извадете го од Reset (ако трепка црвено).
  2. Двоен клик на Start_CNC_Dispenser.bat (во главната папка до index.html):
     - Автоматски го стартува Mach3Bridge.exe минимизирано во позадина;
     - Ја отвора апликацијата index.html во вашиот прелистувач.
  3. Во долниот-лев панел „Машина“ изберете:
     🔌 Mach3 Bridge (127.0.0.1:8765) -> кликнете „🔌 Поврзи“.

Безбедносни и temp\ функции вградени во Mach3Bridge.exe:
  - Автоматски создава потпапка .\temp\ до апликацијата:
    * .\temp\active_job.tap    — точниот G-код што Mach3 го извршува
    * .\temp\tabs_autosave.json — целосна резервна копија на сите табови
                                  на диск (без лимитот од 5 MB во Chrome 49)
  - G28.1 X2 Y2, G1 X1 Y1 F2000 и „Оди на клик“ се блокирани доколку барем
    еден диспензер е спуштен или вентилот е отворен.
  - ⚡ 100ms тест-импулсот прецизно го отвора и затвора вентилот без да
    зависи од подесувањето на Mach3 за G4 (ms наспроти секунди).

Брза проверка дали Bridge-от слуша:
  Додека Mach3Bridge.exe работи, отворете во прелистувач:
    http://127.0.0.1:8765/status
  Треба да врати JSON со "bridgeVersion":"2.0.0" и "mach3Connected":true/false.
